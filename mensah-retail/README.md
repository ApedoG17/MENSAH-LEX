## 📖 Overview

**Mensah-Retail** is a full-stack e-commerce platform that delivers a clean, fast, and intuitive shopping experience for individual customers. From browsing products to checkout, every interaction is crafted with speed and simplicity in mind.

Whether you're a first-time visitor or a returning customer, Mensah-Retail makes online shopping feel effortless.

---

## ✨ Features

- 🏪 **Product Catalog** — Browse a rich collection of products with detailed views
- 🛒 **Shopping Cart** — Add, remove, and manage items with ease
- 🔍 **Search & Filter** — Quickly find exactly what you're looking for
- 📱 **Fully Responsive** — Optimized for all screen sizes, from mobile to desktop
- ⚡ **Blazing Fast** — Built on Next.js for server-side rendering and lightning performance
- 🎨 **Polished UI** — Tailwind CSS-powered design that looks great out of the box

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/ApedoG17/MENSAH-LEX.git
cd MENSAH-LEX/mensah-retail
```

2. **Install dependencies**

```bash
npm install
# or
yarn install
```

3. **Set up environment variables**

Create a `.env.local` file in the root of the project and add your environment variables:

```env
NEXT_PUBLIC_API_URL=your_api_url_here
# Add any other required environment variables
```

4. **Run the development server**

```bash
npm run dev
# or
yarn dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the app running.
